# 🔐 Cyber Security Internship  
## Task 16: Incident Response & Security Breach Simulation

This repository contains the work completed for Task 16 as part of the Cyber Security Internship program.

---

## 📌 Objective

To simulate a security incident and perform proper incident response procedures including detection, containment, eradication, recovery, and documentation.

---

## 🛠️ Tools Used

- Linux Logs
- Windows Event Viewer
- TheHive (Community Edition – Optional)

---

## 🔎 Incident Simulation Performed

A basic security incident was simulated involving:

- Multiple failed login attempts (Brute Force Simulation)
- Suspicious authentication activity
- Unauthorized access attempt

---

## 🧩 Steps Performed

1. Simulated repeated failed login attempts.
2. Analyzed authentication and system logs.
3. Identified suspicious IP address and unusual activity.
4. Classified the incident based on severity level.
5. Contained the incident by isolating the affected user/system.
6. Removed the threat and blocked malicious source.
7. Reset compromised credentials.
8. Restored the system to a secure state.
9. Documented complete incident timeline.
10. Recommended preventive security improvements.
